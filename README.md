## Why?

Flowly Extension was a browser extension (Chrome/Firefox) that enhanced BigBlueButton with emoji reactions, mentions, warnings, break management, GIF support, and more.

Due to **major breaking changes in recent BigBlueButton versions**, the client-side extension approach is no longer viable. The extension can no longer reliably interact with BBB's updated DOM and WebSocket architecture.

## What's next?

The project has evolved into **[FlowlyWeb](https://flowlyweb.com)**, a server-side plugin that integrates directly into BigBlueButton.

**FlowlyWeb** offers:
- Direct integration with the BBB server (no client-side limitations)
- All the features of the extension and more
- Better reliability across BBB updates
- No browser extension installation required for end users

**[Discover FlowlyWeb on flowlyweb.com](https://flowlyweb.com)**

## Legacy

This extension was actively used in educational institutions including [O'clock](https://oclock.io) and [Lutice](https://lutice.online), enhancing video conferencing for hundreds of students and instructors.

### Original features
- Emoji reactions on chat messages
- @mention highlighting
- Active users tracking with GitHub contributor integration
- Technical issue warning system
- Break/pause management with countdown
- GIF support (Tenor API)
- Detachable chat window
- Question highlighting
- Moderator badges
